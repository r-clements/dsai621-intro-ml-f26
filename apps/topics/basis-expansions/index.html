Basis Expansions: Polynomials and Splines

Every fit on this page is ordinary least squares, yi = β0 + β1b1(xi) + … + βJbJ(xi) + εi (ISL 7.7); only the basis functions bj change. Pick a basis and move the slider. Watch the edges: a high-degree polynomial flails there and its ±2 SE band blows up, while a natural spline with the same df stays calm. Drag the orange knot handles to move a knot: a spline changes near that knot, but a polynomial has no knots and every coefficient affects the whole curve. The middle panel shows the columns of the basis matrix, or each column times its coefficient, to see the fit as their sum. The bottom panel sweeps df for the current basis, with knots at quantiles of x. Here df counts every coefficient, including the intercept (df = J + 1), and K is the number of interior knots (boundary knots sit at x = 0 and 1). To keep the fit numerically stable the app uses an equivalent set of df columns that already contains the constant (orthogonal polynomials, B-splines), so there is no separate intercept column; the fitted curve is the same (lecture Result 1.3). ESL's "natural spline with K knots has K basis functions" counts the two boundary knots, so its K is our K + 2. (ISL 7.1–7.4, ESL 5.1–5.2.)

Keyboard and screen reader users: use the arrow keys in the "Basis" group to change the basis, and on the sliders to change the degree, the number of knots or n (Shift+arrow moves 5 steps). Each knot handle in the top chart is a slider: Tab to it and use Left/Right to move it by 0.01 (Shift for 0.05). Tab to the basis chart and use the arrow keys to step through its columns; the selected one is highlighted and described below the chart, and Escape clears it. The statistics line is announced when it changes.
