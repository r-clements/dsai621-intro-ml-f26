Smoothing Splines

A smoothing spline minimizes Σ(yi − g(xi))² + λ∫g″², and its fitted values are a linear smoother, ŷ = Sλy, just as a regression fit is ŷ = Hy. The slider sets the degrees of freedom df = tr(Sλ), and the app finds the λ that gives exactly that df. The shaded band is f̂ ± 2 SE: it widens as df grows, and it is widest at the edges, where each fitted value rests on fewer neighbours. The bottom chart sweeps df for this sample. Bias² falls and variance rises with df, and their sum (plus σ²) is the U-shaped expected test error. LOOCV, computed from this one sample, tracks that curve, while training MSE keeps falling. Tick the box to overlay a natural cubic spline with the same df (knots at quantiles of x), as in last lecture. λ here is SciPy's, with x on [0, 1]. (ISL 7.5, ESL 5.4–5.5.)

Keyboard and screen reader users: use the arrow keys on the sliders (Shift+arrow moves 5 steps). Clicking the error chart sets df; the df slider does the same from the keyboard. Each chart has a text description, and the statistics table, which has every number shown in the charts for the current df, is announced when it changes.

SE(f̂(x)) = σ̂ √(Σi ℓi(x)²), the same formula as Var f̂(xi) = σ²hii for a regression fit, with Sλ in place of H. σ̂² = RSS / (n − df).

Error against df: bias² + variance

  • expected test error (solid)
  • bias² (dashed)
  • variance (dash-dot)
  • LOOCV, this sample (dashed, circles)
  • training MSE, this sample (dotted)
  • current df (diamonds)

Bias², variance and expected test error are exact averages over the training xi, holding the xi fixed: bias² = (1/n)Σ(E f̂(xi) − f(xi))², variance = (σ²/n) tr(SλSλT), and expected test error = σ² + bias² + variance for a new Y at each xi. They depend on f and the xi but not on this sample's y. LOOCV = (1/n)Σ((yi − f̂(xi)) / (1 − Sii))². Very large values at small df are clipped. Click the chart to set df.
