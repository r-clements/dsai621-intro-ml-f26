Decision Trees: Gini, Entropy and Error

One classification problem with four predictors, x₁ to x₄, each uniform on 0 to 10. The truth is class 2 when x₂ is above the wavy curve x₂ = 5 + 3 sin(0.8 x₁) and x₃ ≥ 2; otherwise class 1. x₄ is pure noise, and 15% of labels are flipped at random, so the Bayes error is 0.15. Trees cut parallel to the axes, so they can only follow the wave with a staircase: more leaves follow it more closely (less bias) but fit more noise (more variance). Three trees are grown on the same 400 training points: one splits by the Gini index, one by entropy and one by the classification error. Choose how to stop them and set the value, then press Step to watch each tree reach that stopping point one greedy split at a time; each split shows its reduction Δ in that tree's own impurity measure. Draw a new sample to see how much the trees change from sample to sample, and read the bias–variance plots at the bottom to see why. (ISL 8.1; ESL 9.2.)

Keyboard: the stopping rules are radio buttons (arrow keys move between them), the value is a slider (arrow keys), and the rest are buttons. Each tree's splits are also listed as text under "Rules as text", each bias–variance plot's values are under "Values as text", and a summary of the three trees is announced after each change.

Bias and variance for this stopping rule

Each point is one value of the stopping rule, placed at the average size of its trees. The numbers come from 51 simulated training sets of 400 points. Test error is the average over the 51 trees; bias is how far the majority vote of the 51 trees is above the Bayes error; and variance is how much worse a single tree does, on average, than that majority vote. So test error − 0.15 = bias + variance. (With 0–1 loss the variance can dip just below 0 for very small trees: where the majority vote is wrong, a tree that disagrees with it is right.) The enlarged points and the dashed vertical line mark the current value.
