1. Smoothing splines

1.1 Review

g^λ=arg⁡ming∑i=1n(yi−g(xi))2+λ∫(g″(t))2dt

Solution: a natural cubic spline with knots at all points,

g(x)=β0+∑j=1n−1βjbj(x)

Fitting, with the penalized RSS:

PRSSλ(β)=(y−Bβ)T(y−Bβ)+λβTΩβ
⇒β^=(BTB+λΩ)−1BTy
g^λ=B(BTB+λΩ)−1BT⏟Sλy

Annotation Sλ: smoother matrix.

1.2 Fitted values

g^λ=Sλy

For xi from the training set,

g^λ(xi)=∑j{Sλ}ijyj

Annotation Weighted average of y’s.

Commentary Each row of Sλ sums to 1, since a constant is never penalized and is fitted exactly. Some weights can be negative, though, so it isn’t an average in the strict sense.

Note: Sn×n is symmetric, but not a projection matrix: S2≠S.

1.3 d.f. and λ

d.f.λ=tr(Sλ)

= # of knobs the fit can turn, but our n knobs are limited by λ, so d.f. = some decimal value.

Choose λ: use C.V., or LOOCV.

LOOCV:RSSLOOCV(λ)=∑i=1n(yi−g^λ(i)(xi))2 =∑i=1n(yi−g^λ(xi)1−{Sλ}ii)2

Annotation g^λ(i): the model without xi.

Commentary This is the same shortcut as LOOCV for OLS in DSAI 601, with hii replaced by {Sλ}ii (ISL 5.1.2, 7.5.2). It needs only one fit per λ.

Open questions:

  • What about p>1?
  • What about categorical predictors or Y?
  • Interactions?

2. Generalized additive models (GAMs)

2.1 The model

yi=β0+f1(xi1)+⋯+fp(xip)+εi

fj: unspecified function of one predictor.

wage=β0+f1(year)+f2(age)+f3(edu)+ε

If, e.g., f2(age)=β2age ← linear

Interpret fj as the effect of xj while holding the other predictors fixed.

Note: fj can be linear, polynomial, spline, step function, etc.

2.2 GAMs with smoothing splines

PRSS(β0,f1,…,fp)=∑i=1n(yi−β0−∑j=1pfj(xij))2+∑j=1pλj∫(fj″(tj))2dt

Possible error in original The integration variable is tj, so the differential should be dtj, as in ESL 9.1.1.

Like before, the minimum is reached if the f^j are natural cubic splines with knots at all values of x1j,…,xnj.

Side note Centering: each x is centered, then β^0=y¯, and every f^j is centered around y=0 and

∑i=1nf^j(xij)=0

Commentary Strictly, it is the constraint ∑if^j(xij)=0 that gives β^0=y¯ (ESL 9.1.1). Centering x achieves that only when fj is linear; a nonlinear f^j has to be centered itself.

wage^=y¯+f^1(year)+f^2(age)+f^(edu)

Possible error in original The last term is missing its subscript: f^3(edu).

Example (written in a second colour beside Figure 3): X=(2020,30,Grad).

2.3 Backfitting

Intuition:

yi=β0+β1xi1+β2xi2+εi

Start with β0=y¯ and β1=β2=0:

y=y¯+β1x1+β2x2

Transcription note In the original, arrows above β1 and β2 are each labelled 0.

Backfitting, one coefficient at a time
StepResponse (ri)RegressionEstimate
1. update β1 yi−y¯ ri=β1(1)xi1 β^1(1)
update β2 yi−y¯−β^1(1)xi1 ri=β2(1)xi2 β^2(1)
2. update β1 yi−y¯−β^2(1)xi2 ri=β1(2)xi1 β^1(2)
update β2 yi−y¯−β1(2)xi1 ri=β2(2)xi2 β^2(2)

Possible error in original In the last row the response uses β1(2) without its hat; it should be the estimate β^1(2) from the row above. The second set of notes, below, has the hat.

For the first update, as vectors:

r=(y1−y¯y2−y¯⋮yn−y¯) x1=(x11x21⋮xn1) r=β1x1

Transcription note The original writes the predictor column as X1 and the response as r; they are written here as bold length-n vectors, following the course notation.

Backfitting algorithm (ESL 9.1.1)

Transcription note From here to the end of Section 2.3, the notes come from a second set, Backfitting.pdf (pages 6–8), which covers the algorithm in more detail.

Fix all fk:k≠j:

PRSS=∑i=1n(yi−β0−∑k≠jfk(xik)⏟ri(j)−fj(xij))2+λj∫(fj″(t))2dt+const

Annotation The bracketed part is ri(j). The constant is the penalties for all fk≠j. Think of ri(j) as the response:

∑i=1n(ri(j)−fj(xij))2+λj∫fj″(t)2dt

Algorithm:

  1. Set β^0=y¯ and f^j=0 for all j.

  2. Cycle over j=1,2,…,p:

    f^j←Sj(y−β^01−∑k≠jf^k)

    Annotation The argument written out, the partial residual r(j):

    (y1⋮yn)−[(y¯⋮y¯)+(f^1(x11)+f^2(x12)+⋯⋮f^1(xn1)+⋯)]=r(j)

    Commentary The written-out sum, which starts f^1+f^2+⋯, should skip k=j: as in the line above it, the partial residual leaves out f^j.

    Sj(r(j))=smoothing spline with r(j) as response
    f^j=arg⁡minfj∑i=1n(ri(j)−fj(xij))2+λj∫(fj″(t))2dt

    Annotation Fit a smoothing spline for predictor j where y=r(j).

    Center f^j:

    f^j←f^j−(1n∑if^j(xij))1

    Annotation An arrow points at the subtracted term: it is the vector (f¯j,…,f¯j)T.

  3. Repeat step 2 until convergence: the f^j don’t change much.

Intuition, three rounds

yi=β0+β1xi1+β2xi2+εiβ0=y¯,β^1=β^2=0

For GAMs, model r as a smoothing spline of r on xij.
