2.1 Basis functions

We want to use least squares. With p=1:

yi=β0+β1b1(xi)+β2b2(xi)+⋯+βJbJ(xi)+εi
Bn×(J+1)= ( |||| 1b1(xi)b2(xi)⋯bJ(xi) |||| )
y=Bβ+ε β=(β0⋮βJ)
β^=(BTB)−1BTy
y^=Bβ^ y^=Hy H=B(BTB)−1BT

Corrected from original The original omits two hats on this line, writing Bβ and y=Hy.

f^(x0)=β^0+∑j=1Jβ^jbj(x0)

Commentary The model is nonlinear in x but still linear in the βs. So this is just OLS from DSAI 601 with B in place of X: the hat matrix, standard errors and tests all carry over.
