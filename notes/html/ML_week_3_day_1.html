2.1 One difference

X|Y=k∼N(μk,Σk)

Annotation An arrow points to Σk: depends on k.

⇒ δk(x)= −12log|Σk| −12(x−μk)TΣk−1(x−μk) +logπk

Notice: xTΣk−1x is quadratic in x.

2.2 Tradeoffs

Number of covariance parameters to estimate
MethodCovariancesWith p=2, K=2
LDAp(p+1)/23

  • QDA requires nk>p, or else Σ^k is singular.
  • QDA: more flexible, higher variance, lower bias.
  • Use QDA if n is large or Σ is different for each k.

3. Naive Bayes

3.1 Naive assumption: predictors are independent!

fk(x)=fk1(x1)fk2(x2)⋯fkp(xp)
pk(x)∝πkfk1(x1)⋯fkp(xp)

Possible error in original As the formula for fk(x) shows, the assumption is that the predictors are independent within each class, that is, conditional on Y=k (ISL 4.4.4). The predictors need not be independent overall.

  • fk(x) is no longer multivariate normal.
  • Each predictor gets its own fkj.
  • We can mix quantitative and qualitative predictors.

Possible error in original The NS product is exactly 1/60≈.0167, shown rounded to .02. With the rounded values as written, the fraction is .169/.189≈.89. The .91 comes from the unrounded values, .16875/(.16875+.01667)≈.91. Either way the email is classified as spam.
