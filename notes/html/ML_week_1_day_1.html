1. Intro

1.1 Notation

  • Y: random response / target
  • X=(X1,X2,…,Xp): random predictor vector
  • y= (y1y2⋮yn)
  • X: n×p data matrix
  • p = number of predictors (not βs)
  • n = number of observations (training set)
  • x0: test point
  • x: a fixed data point
  • xi: ith training point
  • β= (β1⋮βp), β0 = intercept
  • 𝒯: training set {(x1,y1),…,(xn,yn)}

Transcription note Two differences from the DSAI 601 (Kutner) notation are worth flagging here, the first time they matter. In DSAI 601, p counted the parameters including the intercept; here p counts predictors only, so a linear model has p+1 coefficients. And plain capitals were vectors in DSAI 601 (for example Y^=HY); here plain capitals are random variables, and the bold letters y and X are the observed response vector and data matrix, so that equation is written y^=Hy. In the handwritten notes the bold letters are written with a double stroke.

Assumption:

Y=f(X)+ε

We want to estimate f.

1.2 Prediction and inference

Prediction: Y^=f^(X). We want f^ to be close to Y.

Annotation An arrow points to “Prediction” with the note: this class.

Inference: how does Y depend on X? f^ is the answer.

1.3 Error

ε is not predictable / observable, with Var(ε)=σ2.

Take X=x (i.e. for some observed point x). Then

E[(Y−Y^)2|X=x] = [f(x)−f^(x)]2 +σ2

Annotation Under [f(x)−f^(x)]2: make this small.

Annotation An arrow points to σ2: can't measure (irreducible).

2. What is f?

2.1 Loss

ℒ(Y,f(X))

Regression: squared error, (Y−f(X))2.

We want to minimize the expected prediction error

EPE(f)=E[(Y−f(X))2]

which is minimized by

f(x)=E[Y|X=x]

the conditional mean of Y given X=x.

2.2 Approximating the conditional mean

Our goal is approximate E[Y|X=x].

3. Training vs testing error

With squared error:

Training error

err‾= 1n ∑i=1n (yi−f^(xi))2

Test error of your fitted model

Err𝒯= E[(Y0−f^(X0))2|𝒯]

where (X0,Y0) is a new random data point.

4. Bias–variance decomposition

Fix x0. f^(x0) is random since 𝒯 is random.

f‾(x0)=E[f^(x0)]

Annotation Under E[f^(x0)]: avg the prediction over all training sets.

Theorem 4.1

E[(Y0−f^(x0))2] =σ2 +[f(x0)−f‾(x0)]2 +E[(f^(x0)−f‾(x0))2]
  • σ2 is the irreducible error.
  • [f(x0)−f‾(x0)]2 is the bias2 of f^(x0).
  • E[(f^(x0)−f‾(x0))2] is the variance of f^(x0).

Annotation Beside the bias term: how far avg fit from truth.

Annotation Beside the variance term: how much f^(x0) varies between training sets.

Transcription note The decreasing curve in Figure 4 has no label in the original. It is labelled bias2 here, following Theorem 4.1, since the test error is the sum of σ2, the squared bias and the variance.
