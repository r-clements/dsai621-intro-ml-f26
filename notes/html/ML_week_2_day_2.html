0. Classification

Y∈{1,2,…,K}, with 0–1 loss:

E[I(Y≠f(X))]

where I(true)=1 and I(false)=0. This is minimized by

f(x)=argmaxkP(Y=k|X=x)

Annotation Under the right-hand side: Bayes classifier (unknown). Approximate it!

1. Logistic regression

Y∈{1,2}.

Assumption: the log odds is linear,

logp(x)1−p(x)=β0+xTβ

1.1 The model

p(x)=P(Y=2|X=x) = eβ0+xTβ 1+eβ0+xTβ = 1 1+e−(β0+xTβ)

1.4 Multinomial regression

Y has K classes (K>2). Pick a baseline class (class K).

log P(Y=k|X=x) P(Y=K|X=x) =βk0+xTβk

Written beside this: K=4, k=1,2, or 3.

Each class gets its own β0k and βk:

P(Y=k|X=x)= eβk0+xTβk 1+∑ℓ=1K−1e(βℓ0+xTβℓ)
P(Y=K|X=x)= 11+∑ℓ=1K−1e(βℓ0+xTβℓ)

Transcription note In the original, the second formula is written only as “11+”: a brace under the sum in the first denominator, drawn in a second colour, has an arrow carrying it into this denominator.

Possible error in original The intercept for class k is written βk0 in the formulas but β0k in “each class gets its own β0k, βk” and in the note on penalties below. Both mean the same parameter; ISL writes βk0.

Softmax:

pk(x)= eβk0+xTβk ∑ℓ=1Keβℓ0+xTβℓ ⇒ ∑k=1Kpk(x)=1

Annotation Pointing to the numerator: each class k gets one. Pointing to the denominator: sum across all classes.

Annotation Prediction: predict the class k with the highest pk(x).

Note: ridge and lasso work on logistic and multinomial regression. Add a penalty (λ∑jβj2 or λ∑j|βj|) to the negative log-likelihood. Don't include β0k.

2. Generative vs discriminative

Logistic (discriminative): P(Y=k|X=x).

An arrow points to the conditioning on X=x: we don't use the distribution of X or of (X,Y).

Generative:

  • P(X,Y)
  • P(X|Y=k)
  • P(Y=k)

then use these, using Bayes' theorem, to get P(Y=k|X=x).

Why?

  • Logistic fails if the classes have perfect separation.
  • If X∼Normal and n is small, generative is more accurate.
Long description of Figure 5

2.1 Bayes' theorem

For events A and B:

P(A|B)= P(A∩B)P(B) = P(B|A)P(A)P(B) = P(A)P(B|A)P(B∩Ac)+P(B∩A)
= P(A)P(B|A)P(A)P(B|A)+P(Ac)P(B|Ac)

For classification:

P(Y=k|X=x)= P(Y=k)P(X=x|Y=k) ∑ℓ=1KP(Y=ℓ)P(X=x|Y=ℓ)

Annotation Under the left-hand side: posterior.

  • P(Y=k)=πk; annotation: prior for class k
  • P(X=x|Y=k)=fk(x): density of x for class k
pk(x)= πkfk(x) ∑ℓ=1Kπℓfℓ(x)

Annotation An arrow labelled posterior points to pk(x).

Annotation The numerator πkfk(x) is highlighted: estimate these.

Annotation Pointing to the denominator: same for all k, ignore these.

So

y^(x)= argmaxkπkfk(x) = argmaxk [logπk+logfk(x)]

Annotation Estimating the prior:

π^k=nkn e.g. # of SPAM# of emails
