1.2 d.f. and λj

Surprisingly, we can write

y^=RyRn×n=R0+⋯+Rp

So, d.f.=tr(R), or count term by term:

Annotation Not exact because of correlation between predictors.

Choosing λj. Each smoother gets its own λj.

  • Focus on d.f. instead
  • Visually check and choose an appropriate d.f.
  • Use generalized CV (GCV):
GCV=1n∑i=1n(yi−y^i)2(1−tr(R)/n)2

Annotation LOOCV shortcut for GAMs.

Commentary GCV takes the LOOCV shortcut and replaces each diagonal entry {R}ii by their average, tr(R)/n. So it approximates LOOCV rather than equalling it (ESL 7.10.1).

Find the lowest GCV over a grid of λ values for each predictor. For example, with 3 predictors (λ1,λ2,λ3) and 3 values each, there are 3×3×3=27 combinations. Number of fits:

  • k-fold CV: k·27
  • LOOCV: n·27
  • GCV: 27

1.4 Pros and cons

Pros:

  • Nonlinear effects are estimated automatically
  • f^j are interpretable
  • d.f. intuitive
  • Interactions can be modeled as
    • a smooth surface (xj and xk are continuous)
    • a different curve per category (xj continuous, xk categorical)
  • Inference: since y^=Ry, use F-tests to compare models.

Cons:

  • Additivity may be wrong. Add interactions yourself.
  • Backfitting might be slow.

  • Recursive, binary splitting: always split a region into two, then split those two regions, and repeat until some stopping criterion.

2.3 Fitting

Transcription note The original numbers this section 2.3, the same as the previous one.

Regression: find regions to minimize

∑m=1|T|∑i∈Rm(yi−y^Rm)2

Annotation Too difficult! Use a greedy algorithm instead.

  • Top-down: all points start in the root node.
  • Greedy: make the best split at each node.

Commentary “Greedy” means each split is the best one available at that moment, with no look-ahead to later splits. ISL calls this recursive binary splitting (ISL 8.1.1).
