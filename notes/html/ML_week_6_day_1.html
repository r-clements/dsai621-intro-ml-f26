1. Decision trees

1.1 Fitting

  • Top-down: start with all points in the root.
  • Greedy: always make the best split.

Algorithm. For a node:

  • For each predictor:
    • For each possible cutpoint s (unique x values):
      • split the data, and calculate the loss.
  • Return the predictor j and cutpoint s that reduce the loss the most.
  • Repeat recursively until a stopping criterion.

Predictions:

y^Rm=1nRm∑i:yi∈Rmyi

Classification

Prediction:

p^mk=1nm∑i:xi∈Rm1(yi=k)

For a node containing 1, 1, 2, 2, 2, 3, 3, 3, 3:

p^m1=29p^m2=39p^m3=49 y^m=arg⁡maxkp^mk=3

Annotation Majority class!!

Loss: 3 impurity measures.

Three impurity measures for a node
MeasureFormulaTwo classes (p=p^m1)
Classification errorE=1−maxkp^mkmin(p,1−p)
Gini indexG=∑k=1Kp^mk(1−p^mk)2p(1−p)
Entropy (cross-entropy, deviance)D=−∑k=1Kp^mklogp^mk−plogp−(1−p)log(1−p)

Example (written in a second colour): a node containing 1, 2, 2, so y^=2, p^m1=13 and p^m2=23.

Classification error: 13 Gini: 13(23)+23(13)or2·13(23) Deviance: −13log13−23log23

Transcription note In the Gini and deviance lines, the 2s in “2/3” are written so that they resemble 3s; they are read here as 2/3, matching p^m2=23.

Total loss of a split:

Total loss=nLntQL+nRntQR
  • Q = impurity measure
  • nt = # of observations in the parent node
  • nL,nR = # of observations in the LHS and RHS

Annotation If the node is 1, 1, 1, 1, 1 (pure): E=0,G=0,D=0.

If the node is 1, 1, 2, 2: E=.5,G=.5,D=−log.5.

1.3 Stopping

Stopping rules
RuleA node is not split when…
Depthit is at depth d
Node sizeit has fewer than nmin points
Leaf sizeit results in child nodes with fewer than k points
# of leavesthere are L leaves (grow best split first)
Improvement (do not use)its best split reduces the loss by less than a threshold

Annotation The improvement rule is highlighted and marked do not use.

Commentary A split that helps little can set up a very good split below it, so stopping on small improvements can miss it. That is why trees are grown large and then pruned (ISL 8.1.1).

1.4 Cost-complexity pruning

Grow a very large tree (T0), then prune leaf nodes. Find a subtree T⊆T0 that minimizes

Cα(T)=RSS(T)+α|T|

Annotation α|T|: penalty on the size of the tree (# of leaves).

1.5 Summary

  • Categorical predictors: encode them first.
  • Missing values: in the training set, send to the best child node; a new point is sent to the larger of nL or nR.
  • Ties go to the first best split.
  • Both child nodes can predict the same thing (classification).

Pros (written in a second colour):

  • No need to transform predictors
  • All splits down the tree are “interactions” with the splits above
  • Nonlinear
Long description of Figure 7

Two curves over a horizontal axis. A solid curve rises steeply to a tall peak near the left and falls off into a long right tail. A dashed curve has a lower, broader and more symmetric peak a little to its right.

Cons (written in a third colour):

  • High variance: a new split near the top changes the entire tree. (Bagging)
  • Not smooth. (Bagging) — RF
  • Can’t model additive structure. (Boosting)

Annotation The words in parentheses, and “RF”, are added beside the cons: the methods that address each one.
