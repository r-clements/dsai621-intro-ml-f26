2. Regularized linear models

  • n = number of observations
  • p = number of predictors
  • β= (β1⋮βp), β0: intercept
  • Xn×p (no column of 1s)

Recall:

  • AIC (λ=2): penalty λ⋅# of β^j≠0
  • BIC (λ=ln(n))

How about λ‖β‖1 or λ‖β‖22?

2.1 Regularization

Overfitting: the model predicts much better on the training set than on testing (unseen) data, i.e. it doesn't generalize well.

Boxed To improve generalization, add a penalty / constraint to the model's fitting objective to discourage complexity (reduce flexibility).

Annotation Written above the box: Regularization

2.2 OLS problems

  1. If p is relatively large, variance is high: 1n∑i=1nVar(y^i) =(p+1)σ2n
  2. Multicollinearity
  3. p>n: XTX is singular

3. Ridge regression

3.1 Ridge regression / L2 regularization

β^λridge= argminβ0,β [ ∑i=1n (yi−y^i)2 +λ ∑j=1p βj2 ]
= argminβ0,β [ ∑i=1n (yi−β0− ∑j=1p xijβj)2 +λ ∑j=1p βj2 ]

Annotation A brace under β0+∑jxijβj points to

y^i=β0+β1xi1+β2xi2+⋯+βpxip

Annotation The penalty ∑j=1pβj2 is boxed and labelled (L2 norm)², ‖β‖22.

3.2 Standardize X

We want all predictors on the same scale, so replace xij with

x~ij= xij−x‾jsj sj= 1n∑i(xij−x‾j)2

Why?

Annotation An example of predictors on very different scales:

  • X1∈{0,1,2,3,4,5}, e.g. number of rooms
  • X2∈[500,5000], e.g. ft²

With an arrow pointing to these: one will dominate the loss function, e.g. β1=500, β2=1.

Important Use x‾j and sj from the training set.

Lemma 3.2. If X is centered, then

β^0=y‾ ⇒ RSS= ∑i=1n ((yi−y‾)− ∑j=1p xijβj)

Possible error in original The square is missing. As written, the terms are not squared, so this sum is not the RSS: positive and negative residuals would cancel. It should be ∑i=1n((yi−y‾)−∑jxijβj)2, as in the ridge objective in 3.1.

You can center y and get the same β^s (without a β^0).

3.3 Solution for β

Aside Hoerl & Kennard (1970) noticed that (XTX+αI) fixes the singularity, so that (XTX+αI)−1 exists and behaves, so

β^=(XTX+αI)−1XTy

which is biased, but its variance is lower!

RSS(β)= (y−Xβ)T (y−Xβ) +λβTβ

Expand, take the derivative, set it to 0, and solve for β:

β^λridge= (XTX+λI)−1 XTy

Annotation λI is underlined, with the note: added some bias to β^s, but reducing variance.

4. Lasso / L1 regularization

4.1 Definition

β^λlasso= argminβ0,β ∑i=1n (yi−y^i)2 +λ ∑j=1p |βj|

Annotation The penalty ∑j=1p|βj| is boxed and labelled L1 norm, ‖β‖1.

4.2 Standardize your predictors!

Written beside this heading: β^0=y‾.

4.3 Solution for β

∂∂βRSS(β)= −2XT(y−Xβ) +λsign(β)

Annotation An arrow points to sign(β): undefined if β=0.

Annotation Must use a numerical method: coordinate descent.

4.4 Hard constraint

Ridge:

β^ridge= argminβ0,β RSS(β0,β) subject to ∑j=1p βj2≤t

Lasso:

β^lasso= argminβ0,β RSS(β0,β) subject to ∑j=1p |βj|≤t

Annotation An arrow labelled Hard constraint points to the condition ∑βj2≤t.

5. λ (tuning parameter)

  • If λ=0 ⇒ OLS.
  • As λ increases, the β^js decrease.
  • Lasso shrinks β^js → 0 (feature selection).
  • Correlated features (x1 and x2): Ridge shrinks β^1 and β^2 together. Lasso shrinks one to 0.
  • Choose λ using a test set, or use cross-validation.

Transcription note The second bullet is written with arrows: “as λ ↗, β^js ↘”.

6. Summary

  • β^0=y‾
  • Ridge won't shrink β^js → 0.
  • Both add bias to β^j, lower the variance, and less flexible than OLS.
