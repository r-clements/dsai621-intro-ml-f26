  \item Show that the expected test error at $x_0$ decomposes as
  \[
    \E\big[(Y - \hat f(x_0))^2\big] = \sigma^2 + \big[\mathrm{Bias}\,\hat f(x_0)\big]^2 + \Var\big(\hat f(x_0)\big).
